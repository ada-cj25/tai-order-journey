# 苔的跟单旅程

网页、后端和微信小程序的私有源码快照。个人所有的产品与代码；公司业务数据由公司所有。

## 目录

- `src/`：桌面网页与移动只读网页。
- `server/`：API、业务规则和数据库迁移。
- `mini-program/`：小程序原型及接口代码，默认模拟模式。
- `customer-agent/`：本地客服演示。
- `deploy/`、`docs/launch/`：部署模板和运行手册；上传本仓库不代表部署或验收通过。

## 本地准备

使用 Node.js 24 和 PostgreSQL 17。运行 `npm ci`，将 `.env.example` 复制为本地 `.env` 并设置自己的数据库连接及随机会话密钥，然后运行 `npm run db:generate`。首次数据库初始化、迁移和角色配置须按 `docs/launch/README.md` 的对应流程执行。

网页开发入口为 `npm run dev`。小程序可从微信开发者工具导入 `mini-program/`；仓库保留游客 AppID，在本地配置自己的 AppID。
