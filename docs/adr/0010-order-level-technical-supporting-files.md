# ADR 0010：海迅单与分解单按销售订单共用

## 决策

技术拆单中的海迅单和分解单属于销售订单级可选资料。每张订单各保留一个可选上传入口，两个入口都允许上传多个文件；如果上传，订单的所有生产区域共同引用这组文件，不要求按区域重复上传。

生产区域仍分别保存设计版本、生产路线、各车间计划面积和物料 Excel 解析。区域技术包提交时由服务端继承订单已有的可选海迅单与分解单引用；两类资料都缺省时，只校验本区域物料解析和生产计划。

## 兼容

历史技术包中已经绑定生产区域的海迅单和分解单继续有效，可作为同订单其他区域的共用资料。新上传的海迅单和分解单不再绑定生产区域；物料 Excel 仍必须绑定其实际生产区域。

## 结果

- 技术人员只上传一次整单支撑文件。
- 没有海迅单或分解单时也可提交生产区域，不形成资料缺口或提交门禁。
- 每个入口可选择多个文件。
- 区域之间不共享物料解析或生产计划。
- 批量提交仍为原子操作，任一区域资料不完整则全部回滚。
