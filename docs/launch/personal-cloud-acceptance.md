## 性能与试点

- 50个登录会话、20个活跃用户、5路附件上传；普通列表和详情p95≤2秒，不含大文件传输。状态：待云压测。
- 首周1–3张真实新单；旧单不导入；稳定后扩到10–20张。
- 出现越权、丢数据、编号冲突、重复事实或错误发货放行，立即暂停新增订单。
- 连续10个工作日无严重问题、关键记录及时率≥95%、日抽查无未解释差异，且至少一张新单真实交付验收后再扩大。
